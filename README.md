# AI Lab Algorithms — Python

A collection of academic Artificial Intelligence lab implementations.

## Included work
- Recursive `encloses` relationship (Prolog-style facts and rules represented in Python)
- Breadth-First Search (BFS) maze solver
- A* search maze solver
- 4-Queens Constraint Satisfaction Problem (CSP) solver
- Tic-Tac-Toe heuristic utility agent

## Concepts demonstrated
Knowledge representation, recursion, uninformed search, informed search, heuristic functions, constraint satisfaction and agent-based decision making.

## Requirements
- Python 3.9 or later for the scripts
- Jupyter Notebook to open the `.ipynb` file

The scripts use Python standard-library modules.

## Run
```bash
python all_tasks.py
```

To play the Tic-Tac-Toe agent:
```bash
python tictactoe_play.py
```

## Important
The Tic-Tac-Toe program uses a heuristic evaluation strategy. It should not be described as a guaranteed unbeatable Minimax agent.
